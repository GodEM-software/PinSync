Windows & Linux · PureRef-Style Infinite Canvas

Pin anything. Sync live. Drag it anywhere.

PinSync combines an infinite visual reference board for images, videos, webpages, audio, 30+ 3D/CAD model formats, free-draw sketches, flowcharts, and code with real-time central server collaboration and native OS drag-out.

Download Releases View on GitHub

Built for Creative & Technical Workflows

30+ 3D & CAD Formats

Inspect GLB, GLTF, OBJ, FBX, STL, USDZ, PLY, STEP, IGES, BREP, Gaussian Splats, and ZIP bundles directly on the board with OrbitControls and wireframe mode.

Central Server & Live Sync

Host the built-in central server or run it on your own VPS. Boards and deduplicated media assets sync in real time over SSE so teammates can refine together.

Native OS Drag-Out

Click, hold, and drag any reference item past the PinSync window border to drop it directly into Explorer, Desktop, Photoshop, or Blender.

Free-Draw, Flowcharts & Text

Sketch with the smooth vector pen (Alt+D), type anywhere on the canvas, or type aaa + Space to draw smart-snapping arrows.

Portable Embedded Boards

Save boards as self-contained .artbrd.json files with all local media assets embedded inside — ready to share across computers.

macOS-Style Floating Dock

Minimal glassmorphic bottom dock, 5 ambient canvas themes, window opacity control, always-on-top mode, and one-key Zen mode (Tab).

Run Your Own Central Server

git clone https://github.com/YOUR_USERNAME/PinSync.git
cd PinSync
npm install
npm run server   # Starts PinSync Central Server on http://0.0.0.0:4580

Desktop Quick Start

npm install
npm start        # Builds and launches PinSync
npm run build:win    # Windows .exe installer & portable
npm run build:linux  # Linux AppImage, .deb (Debian/Deepin), .pacman (Arch)
