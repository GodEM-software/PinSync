User Guide

Get Started with PinSync in Minutes

Follow this quick guide to install PinSync, organize your reference board, collaborate live, and drag assets straight into your creative tools.

STEP 01

Download & Install

Click Download for Windows (.exe Setup) or use the Portable .exe (no installation needed). Linux users can run the .AppImage, .deb, or .pacman package.

STEP 02

Navigate the Canvas

Pan freely with Middle Drag, Alt + Left Drag, or Space + Left Drag. Zoom smoothly with the Mouse Wheel. Drag the frameless window anywhere with Right Mouse Drag.

STEP 03

Toggle Zen Mode & Always-on-Top

Press Tab to hide the dock for distraction-free reference viewing, and pin PinSync above Photoshop or Blender using the TopBar pin toggle.

DROP & PASTE

Drop Files or Paste Anywhere

Drag images, videos, audio, code files, or 3D/CAD models directly onto the board. Press Ctrl+V to paste clipboard screenshots, URLs, or code.

DRAW & ANNOTATE

Type, Sketch & Connect

Start typing anywhere on empty canvas to create inline text. Press Alt+D for the Free-Draw Pen, or type aaa + Space to draw smart arrows.

EYEDROPPER & CROP

Color Swatches & Non-Destructive Crop

Press Alt+I to sample any screen color into a copyable hex swatch card. Hold Alt+Shift+Drag on any image to crop non-destructively.

CENTRAL SERVER

Host or Connect to a Server

PinSync includes a built-in Central Server on port 4580 (or run npm run server standalone). Open the Online modal in the TopBar.

SHARE ROOM ID

Real-Time SSE Collaboration

Share your Room / Board ID (board_xxxxxx) with teammates. Every edit broadcasts over Server-Sent Events (SSE) in real time.

DEDUPLICATION

Automatic SHA-1 Asset Sync

Images, videos, audio, and 3D models are deduplicated by SHA-1 hash on the central server so collaborators automatically download and render every asset.

PORTABLE SAVE

Self-Contained .artbrd.json

Saving a board embeds all referenced local media files directly into a single .artbrd.json file so it opens cleanly on any other computer.

NATIVE DRAG-OUT

Drag Out to Any App

Click, hold, and drag any item past the edge of the PinSync window to drop it directly onto your Desktop, File Explorer, Photoshop, or Blender.

QUICK ARRANGE

Optimal Packing & Search

Press Ctrl+P to auto-arrange items neatly, or Ctrl+K to jump to any item on large boards.
