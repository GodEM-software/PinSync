User Guide

Up and Running in 4 Steps

Everything you need to install, organize, collaborate, and export from PinSync.

01 / INSTALL

Download & Launch

Choose Windows Setup (.exe), Windows Portable, or Linux (.AppImage / .deb). First 50 users get it completely free.

02 / NAVIGATE

Pan, Zoom & Move Window

Pan with Middle, Alt+Left, or Space+Left Drag. Zoom with the wheel. Drag the frameless window via Right Drag.

03 / FOCUS

Zen Mode & Always-on-Top

Press Tab to hide the dock for distraction-free viewing, and pin PinSync above your creative apps.

01 / DROP & PASTE

Add Any Media or Code

Drag files onto the canvas or press Ctrl+V to paste screenshots, URLs, or syntax-highlighted code snippets.

02 / SKETCH

Inline Text, Pen & Arrows

Start typing anywhere on empty canvas. Press Alt+D to sketch or type aaa + Space for smart arrows.

03 / SAMPLE

Eyedropper & Crop

Press Alt+I to pick any screen color into a hex swatch. Hold Alt+Shift+Drag to crop images non-destructively.

01 / SERVER

Built-in Central Server

Start the built-in server on port 4580 or run npm run server standalone for team hosting.

02 / ROOM ID

Share a Board ID

Open the Online modal and share your board_xxxxxx Room ID so peers sync edits over SSE in real time.

03 / ASSETS

Automatic Deduplication

Media and 3D models are hashed with SHA-1 and stored centrally so teammates automatically render every asset.

01 / PORTABLE

Self-Contained .artbrd.json

Saving a board embeds all local media directly inside one .artbrd.json file so it opens cleanly anywhere.

02 / DRAG-OUT

Native OS Drag-Out

Click, hold, and drag any item past the edge of the PinSync window to drop it into Explorer, Photoshop, or Blender.

03 / ORGANIZE

Optimal Pack & Jump

Press Ctrl+P to auto-arrange items neatly, or Ctrl+K to search and jump on huge boards.
